## single-page-cv

Halaman CV berbasis web yang dibuat menggunakan HTML semantik murni tanpa CSS framework maupun styling eksternal.

### Key Requirements

- **Semantic HTML** — menggunakan tag HTML yang sesuai makna kontennya
- **SEO Meta Tags** — membantu halaman ditemukan oleh mesin pencari
- **Open Graph (OG) Tags** — mengoptimalkan tampilan saat dibagikan di media sosial
- **Favicon** — ikon kecil yang muncul di tab browser

### Struktur Folder

```
project-beginner/
├── single-page-cv/
│   ├── index.html            # File utama halaman CV
│   ├── favicon-32x32.png     # Favicon ukuran 32x32
│   ├── favicon-16x16.png     # Favicon ukuran 16x16
│   ├── apple-touch-icon.png  # Icon untuk perangkat Apple
│   ├── site.webmanifest      # Web app manifest
│   └── og-image.jpg          # Gambar untuk Open Graph (1200x630px)
└── README.md
```

### Cara Menjalankan

1. Clone repository ini
   ```bash
   git clone https://github.com/Dekaa19/project-beginner.git
   ```
2. Masuk ke folder proyek
   ```bash
   cd project-beginner/single-page-cv
   ```
3. Buka `index.html` langsung di browser — tidak perlu server atau instalasi apapun
